# Assets

Recursos visuais gerais usados pela B.M Flow ficam nesta pasta.

```text
Assets/
└── Images/             # imagens estáticas incorporadas ou usadas pela interface
    └── windows11.png   # botão Iniciar da dock
```

Mascotes e cursores permanecem em suas pastas próprias porque possuem estrutura e carregamento específicos.

Ao adicionar um asset, use um nome descritivo, mantenha o arquivo otimizado e registre autoria, origem e licença em [`docs/ASSETS.md`](../docs/ASSETS.md).
