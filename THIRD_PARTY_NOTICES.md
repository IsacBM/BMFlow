## Windows 11 Fluent Cursor v3

- Autor: Arteffect10520
- Página oficial: https://www.deviantart.com/arteffect10520/art/Windows-11-Fluent-Cursor-v3-1009751409
- Uso na B.M Flow: a interface oferece um link para a página oficial e uma pasta local para o usuário instalar manualmente os arquivos.
- Redistribuição: o pacote não faz parte da pasta de destino vazia `Cursors/Fluent-v3-Arteffect/`. Não adicione os arquivos ao repositório sem confirmar as condições do autor.
