# Assets e créditos

O repositório contém código e documentação, mas também imagens, sprites e cursores. A Licença MIT da raiz cobre o código-fonte e a documentação produzidos para a B.M Flow; ela não deve ser interpretada como uma declaração automática de licença sobre todo recurso visual.

## Adicionar um recurso

Todo novo asset deve trazer, na mesma contribuição:

- nome e autor;
- URL de origem, se houver;
- licença ou permissão verificável;
- alterações feitas no original;
- arquivo de licença quando exigido.

Se a redistribuição não for permitida, a aplicação pode orientar o usuário a obter o recurso na fonte oficial, sem copiar o arquivo para o repositório.

## Checklist antes de uma release pública

- [ ] Confirmar autoria dos assets próprios.
- [ ] Guardar autorização dos colaboradores responsáveis pelos assets.
- [ ] Remover qualquer arquivo cuja licença não permita redistribuição.
- [ ] Atualizar `THIRD_PARTY_NOTICES.md` com versões, autores, links e licenças.
- [ ] Verificar se capturas de tela não expõem dados pessoais.
